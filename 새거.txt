[ 0. 목표 ]
================================================================

목적:
  energyplus.kr (동네학원 찾기 - 에너지+) 사이트의
  전체 30,613개 index.html을 Python 스크립트 1회 실행으로 완전 생성.

  기존 HTML 파일을 전부 삭제하고 새로 만드는 방식.
  수정이 아닌 완전 새 생성 (overwrite).
  기존 HTML 파싱/상속 없음 — 모든 내용을 소스 3종 + NEIS API로 생성.

입력 소스 3종:
  1. 학원목록.txt              → 도/시/동 조합 436개
  2. 학년학원키워드.txt         → 36개 키워드 (초등10 중등14 고등12)
     메인학원키워드.txt         → 29개 키워드
  3. 본문뽑기/[경로]/result.html → 본문 콘텐츠 JSON

추가 소스:
  4. NEIS API                  → 전 레벨 학원카드 16개 실시간 호출

출력:
  새로운학원/[도]/[시]/[동]/[학년]/[키워드]/index.html
  총 30,613개 파일

생성 스크립트 파일명 (예정): gen_all.py

[ 4. result.html 구조 ]
================================================================

  JSON 형식. 전 레벨(1~5) 동일한 구조.

  {
    "meta": "페이지 설명 (→ description / og:description / twitter:description)",
    "section1": { "h2": "인삿말", "p": "..." },
    "section2": { "h2": "[지역] 학군지 특징", "p": "...", "list": [...] },
    "section3": { "h2": "[학원명] 소개", "p": "...", "list": [...], "table": [...] },
    "section4": { "h2": "[학년] 학부모의 흔한 실수", "p": "...", "table": [...] },
    "section5": { "h2": "해당 학원의 커리큘럼", "p": "...", "list": [...] },
    "section6": { "h2": "종합 학습 전략", "p": "...", "list": [...] },
    "section7": { "h2": "추천하는 학생", "p": "...", "list": [...] },
    "section8": { "h2": "FAQ 관련", "faq": [{"q": "...", "a": "..."}] }
  }

  규칙:
    - h2 값은 가공 없이 그대로 HTML에 삽입
      예) "h2": "경기도 학군지 특징" → <h2 class="section-title">경기도 학군지 특징</h2>
    - result.html 없는 경로는 스킵 (해당 index.html 미생성)

[ 5. result.html 섹션별 HTML 렌더링 규칙 ]
================================================================

  section1 (인삿말) — p만:
    <section class="section">
      <div class="container">
        <h2 class="section-title">[section1.h2]</h2>
        <p class="section-desc">[section1.p]</p>
      </div>
    </section>

  section2 / section5 / section6 / section7 — p + list:
    <section class="section">
      <div class="container">
        <h2 class="section-title">[h2]</h2>
        <p class="section-desc">[p]</p>
        <ul class="content-list">
          <li>[list 항목]</li>
          ...
        </ul>
      </div>
    </section>

  section3 — p + list + 정보 테이블 (2열):
    <section class="section">
      <div class="container">
        <h2 class="section-title">[h2]</h2>
        <p class="section-desc">[p]</p>
        <ul class="content-list">
          <li>[list 항목]</li>
        </ul>
        <table class="info-table">
          <tbody>
            <tr><th scope="row">학원명</th><td>[내용]</td></tr>
            <tr><th scope="row">수강료</th><td>[내용]</td></tr>
            <tr><th scope="row">주소</th><td>[내용]</td></tr>
          </tbody>
        </table>
      </div>
    </section>

  section4 — p + 비교 테이블 (3열):
    <section class="section">
      <div class="container">
        <h2 class="section-title">[h2]</h2>
        <p class="section-desc">[p]</p>
        <table class="compare-table">
          <thead>
            <tr><th>구분</th><th>대상</th><th>내용</th></tr>
          </thead>
          <tbody>
            <tr>
              <td>[구분]</td>
              <td>[대상]</td>
              <td>[내용]</td>
            </tr>
            ...
          </tbody>
        </table>
      </div>
    </section>

  section8 (FAQ):
    HTML:
    <section class="section">
      <div class="container">
        <h2 class="section-title">[section8.h2]</h2>
        <dl class="faq-list">
          <dt class="faq-q">Q. [faq[i].q]</dt>
          <dd class="faq-a">[faq[i].a]</dd>
          ...
        </dl>
      </div>
    </section>

    JSON-LD: head의 FAQPage에 동일 내용 반영 (내용 반드시 일치)

  시맨틱 태그 이유:
    <ul><li>     → 크롤러가 "목록"으로 인식
    <table><th>  → 크롤러가 "표"로 인식 (th scope로 헤더 명시)
    <dl><dt><dd> → 크롤러가 "정의 목록/Q&A"로 인식

[ 6. NEIS API — 학원카드 레벨별 호출 규칙 ]
================================================================

  API 엔드포인트: https://open.neis.go.kr/hub/acaInsTiInfo
  인증키: 1e15a9adec0647c4a5d52cfc2c5cc9fe
  고정 파라미터: Type=json, pIndex=1, pSize=1000

  ─── 공통 필터 (전 레벨) ───────────────────────────────────────

    REG_STTUS_NM = "개원"                    ← 폐원 제외
    PSNBY_THCC_CNTNT 비어있지 않음           ← 수강료 없는 것 제외
    LE_CRSE_LIST_NM 또는 LE_CRSE_NM에
      수학 / 영어 / 국어 중 하나 포함
    학원명 6글자 이상 동일 시 중복 제거
    수학 → 영어 → 국어 순환 인터리브로 16개 추출

  ─── 레벨1 (도) ────────────────────────────────────────────────

    호출 파라미터:
      ATPT_OFCDC_SC_CODE = 도 코드 (예: B10 서울특별시)

    추가 필터: 없음
    폴백: 없음 (도 전체 수집)

  ─── 레벨2 (시/구) ─────────────────────────────────────────────

    호출 파라미터:
      ATPT_OFCDC_SC_CODE = 도 코드
      ADMST_ZONE_NM = 시/구명 (예: 마포구)

    추가 필터: 없음
    폴백: 없음 (시/구 전체 수집)

  ─── 레벨3 (동) ────────────────────────────────────────────────

    호출 파라미터:
      ATPT_OFCDC_SC_CODE = 도 코드
      ADMST_ZONE_NM = 시/구명

    추가 필터:
      FA_RDNDA 괄호 안에 동명 포함된 것만
      예) FA_RDNDA = "...(상암동, 상암 아파트)" → 상암동 ✓

    폴백:
      5개 미만이면 → 동 필터 제거하고 시/구 전체 사용

  ─── 레벨4 (동/학년) ───────────────────────────────────────────

    호출 파라미터:
      ATPT_OFCDC_SC_CODE = 도 코드
      ADMST_ZONE_NM = 시/구명

    추가 필터:
      FA_RDNDA 동 필터 (레벨3 동일)
      + 학년별 과목 필터 (LE_CRSE_LIST_NM 또는 LE_CRSE_NM):

        초등     → "초등" 포함 우선
        중등     → "중등" 또는 "중학" 포함 우선
        고등     → "고등" 또는 "고학" 포함 우선
        메인학원 → 학년 필터 없음 (수학/영어/국어 전체)

    폴백 순서:
      16개 미만 → 폴백1: 학년 필터 제거 (동 필터만 유지)
      여전히 5개 미만 → 폴백2: 동 필터도 제거 (시/구 전체 + 학년 필터)
      여전히 5개 미만 → 폴백3: 학년 필터도 제거 (시/구 전체)

  ─── 레벨5 (동/학년/키워드) ────────────────────────────────────

    레벨4와 완전히 동일한 호출 규칙 적용.
    키워드는 URL / title / description에만 사용.
    학원카드 필터에는 키워드 미적용.
    (동네 학원 모음 성격 — 키워드 무관하게 지역 학원 전체 표시)

  ─── 레벨별 정리표 ─────────────────────────────────────────────

    레벨 │ API 파라미터          │ 추가 필터            │ 폴백

  예시: https://res.cloudinary.com/dg9uf6vh6/image/upload/q_auto/location/노원구 하계동.webp

■ 레벨별 위치사진 사용 규칙

  레벨1 (도 단위)
    → 위치사진 없음 (섹션 H2-2 자체 미출력)

  레벨2 (시/구 단위)
    → 해당 시/구에 속하는 점들의 5번째 컬럼 값 전부 수집
    → 수집된 public_id 개수만큼 <img> 태그 출력
    → alt값: 위치사진1, 위치사진2, 위치사진3 ... (순서대로 n 증가)
    예시) 노원구 페이지 → 노원구 하계동 1장만 존재 → 위치사진1 1장
    예시) 일산 페이지 → 일산 덕이점, 일산 마두점, 일산 삼송점 ... → 위치사진1~N 여러 장

  레벨3 (동 단위)
    → 해당 점의 5번째 컬럼 값 1개 → location/[값] 1장
    → alt값: 위치사진1

  레벨4 (학년 단위)
    → 레벨3과 동일: 5번째 컬럼 값 1개 → 1장, alt=위치사진1

  레벨5 (키워드 단위)
    → 레벨3과 동일: 5번째 컬럼 값 1개 → 1장, alt=위치사진1

■ 레벨2 매칭 방법 (코드 로직)
  1. 학원목록.txt에서 레벨2(시/구)가 일치하는 모든 행 수집
  2. 각 행의 5번째 컬럼 값 → public_id 리스트 생성
  3. location_ids.txt에서 해당 public_id 존재 여부 확인
  4. 존재하는 것만 순서대로 <img> 출력, alt=위치사진{n}
