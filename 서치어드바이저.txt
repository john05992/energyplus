[ 1. Canonical (선호 URL) ]
================================================================

- <link rel="canonical" href="절대경로URL"> 사용
- 반드시 절대경로: https://energyplus.kr/경기도/광주시/
- 상대경로 사용 금지: /경기도/광주시/ (X)
- 동일 콘텐츠가 여러 URL로 접근 가능한 경우 대표 URL 지정 필수

적용:
  모든 페이지의 canonical은 https://energyplus.kr/[경로]/ 형식으로


================================================================
[ 2. robots 메타 태그 ]
================================================================

권장:
  <meta name="robots" content="index, follow">

의미:
  index   = 검색결과에 이 페이지 포함
  follow  = 이 페이지 내 링크 수집
  noindex = 검색결과 제외
  nofollow= 링크 수집 안 함

주의:
  noindex 페이지는 검색에서 완전 제외됨
  redirect 페이지에는 메타 태그가 제대로 반영 안 될 수 있음


================================================================
[ 3. Title 태그 ]
================================================================

규칙:
  - 페이지마다 고유한 제목 (사이트 전체 동일 제목 금지)
  - 콘텐츠 주제를 명확하게 설명
  - 2회 이상 키워드 반복 금지
  - 스팸성 키워드 나열 금지
  - 과도하게 긴 제목 금지
  - 자주 변경 금지 (검색 노출 불이익)
  - <title> 태그는 페이지당 반드시 1개만

문제 케이스 (네이버가 불이익 줌):
  - title 요소가 없는 경우
  - title 요소가 2개 이상인 경우
  - 사이트 내 여러 페이지가 동일한 title인 경우
  - title이 과도하게 긴 경우

적용:
  [동/학년/키워드] | 동네학원 찾기 - 에너지+


================================================================
[ 4. Description 메타 태그 ]
================================================================

규칙:
  - 페이지마다 고유한 설명
  - 1~2개 문장의 짧은 단락
  - 2회 이상 키워드 반복 금지
  - 스팸성 키워드 나열 금지
  - 본문 전체 복사 붙여넣기 금지
  - title과 동일한 내용 금지
  - 사이트 내 여러 페이지 동일 description 금지
  - 자주 변경 금지

주의:
  실제 검색 스니펫은 네이버가 자동 추출 (description 그대로 안 나올 수 있음)
  → 그래도 고유하고 정확하게 작성해야 함


================================================================
[ 5. OG (Open Graph) 태그 ]
================================================================

필수 항목:
  <meta property="og:type" content="article">     ← 서브페이지
  <meta property="og:title" content="...">
  <meta property="og:description" content="...">
  <meta property="og:image" content="절대경로URL">
  <meta property="og:url" content="절대경로URL">
  <meta property="og:site_name" content="...">
  <meta property="og:locale" content="ko_KR">

OG 이미지 규격 (중요):
  - 크기: 150x150px 이상
  - 파일 사이즈: 5,000 byte 이상
  - 가로:세로 비율: 3:1 이하 (1200x630 = 약 1.9:1 → OK)
  - 페이지마다 고유 이미지 사용 (전체 동일 이미지 금지)
  - 로고/배너 반복 이미지 사용 금지

우리 현황:
  Cloudinary 텍스트 오버레이로 페이지마다 URL 다름 → OK
  1200x630 비율 → OK

[ 6. Twitter 태그 ]
================================================================

  <meta name="twitter:card" content="summary_large_image">
  <meta name="twitter:title" content="...">
  <meta name="twitter:description" content="...">

네이버도 소셜 태그 정보를 페이지 분석에 활용함

[ 7. Favicon ]
================================================================

규격:
  - href는 반드시 절대경로 (상대경로 금지!)
  - 정사각형, 최소 16px 이상
  - 고유한 이미지 사용
  - URL 자주 변경 금지

지원 포맷: ICO, PNG, GIF, JPEG, SVG 등

rel 속성 우선순위:
  1. shortcut icon
  2. icon
  3. 기본 favicon.ico
  4. apple-touch-icon
  5. apple-touch-icon-precomposed

올바른 마크업:
  <link rel="icon" href="https://energyplus.kr/images/favicon.ico">
  <link rel="icon" type="image/png" sizes="32x32" href="https://energyplus.kr/images/favicon-32x32.png">
  <link rel="icon" type="image/png" sizes="16x16" href="https://energyplus.kr/images/favicon-16x16.png">
  <link rel="apple-touch-icon" href="https://energyplus.kr/images/로고.jpg">

우리 현황 버그:
  현재 /images/favicon.ico 형태의 상대경로 사용 중 → 절대경로로 수정 필요


================================================================
[ 8. H1 태그 ]
================================================================

규칙:
  - 페이지당 H1은 반드시 1개만
  - 2개 이상이면 네이버 검색로봇이 이해하기 어려운 구조로 판단
  - 불이익 발생 가능

우리 현황:
  히어로 영역에 H1 1개만 사용 → OK


================================================================
[ 9. 이미지 Alt 속성 ]
================================================================

규칙:
  - 모든 콘텐츠 이미지에 alt 속성 필수
  - alt 내용은 이미지 내용을 설명하는 텍스트
  - alt="" (빈 값)은 장식용 이미지에만 허용

적용:
  히어로 이미지: alt="[지역명] 학원 실제 내부"
  학원카드 이미지: alt="[지역명] [학원명] 내부"
  로고 이미지: alt="동네학원 찾기 - 에너지+ 로고"


================================================================
[ 10. 링크 처리 ]
================================================================

규칙:
  - 반드시 <a href="URL"> 형식 사용
  - JS onclick / JS함수 방식 금지
  - 동적으로 URL 변경되는 링크 금지
  - 절대경로 또는 루트 상대경로 사용 권장

좋은 예:  <a href="/경기도/광주시/">광주시</a>
나쁜 예:  <span onClick="javascript:goto(A)">광주시</span>
나쁜 예:  <a href="javascript:createLink(1)">광주시</a>

우리 현황:
  region-list, back-nav 모두 <a href> 사용 → OK


================================================================
[ 11. URL 구조 ]
================================================================

규칙:
  - 사람이 읽기 쉬운 URL (의미 있는 경로명)
  - fragment(#) URL로 다른 콘텐츠 표현 금지
    → 네이버 로봇은 # 이후를 제거하고 수집
  - JS로만 구성된 SPA URL (해시뱅 #!) 금지
  - URL 파라미터 최소화
  - HTTPS 사용 권장
  - 소문자 사용

좋은 예:  /경기도/광주시/경안동/
나쁜 예:  /page#경안동
나쁜 예:  /page#!/경안동


================================================================
[ 12. JavaScript 관련 ]
================================================================

규칙:
  - 주요 콘텐츠는 HTML로 서버사이드 렌더링 (SSR) 권장
  - JS로만 렌더링되는 콘텐츠는 수집 누락 위험
  - CSS/JS 파일이 robots.txt로 차단되어 있으면 페이지 해석 불완전
  - JS redirect 대신 HTTP 301/302 redirect 사용
  - JS에 timestamp/hash 값 넣어 URL 강제 변경 금지

우리 현황:
  순수 정적 HTML → JS 렌더링 없음 → OK
  WCS 스크립트는 추적용으로 콘텐츠와 무관 → OK
  단, wcslog.js에 defer 추가 권장 (크리티컬 체인 제거)


================================================================
[ 13. 사이트맵 & RSS ]
================================================================

  - 웹마스터도구에 sitemap.xml 제출
  - RSS 피드 제출 (최신 글 본문 전체 포함)
  - 사이트맵 내 URL은 절대경로 사용
  - 호스트가 등록된 사이트와 일치해야 수집


================================================================
[ 14. 색인 불용 케이스 (피해야 할 것) ]
================================================================

  - HTML 내용 없는 페이지 (JS만으로 구성)
  - 소프트 404: 존재하지 않는 페이지가 200 응답 반환
  - noindex 설정된 페이지
  - CSS/JS 리소스가 robots.txt에 의해 차단된 경우
  - frame 태그 안에 주요 콘텐츠 배치


================================================================
[ 15. 중복 콘텐츠 ]
================================================================

  - 동일 콘텐츠를 여러 URL로 제공 시 불이익
  - canonical로 대표 URL 지정 필수
  - 사이트 내 모든 페이지 title/description이 동일하면 불이익
  - 중복 사이트 개설 금지
