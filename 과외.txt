[ 0. 목표 ]
================================================================

목적:
  energyplus.kr/과외/ 하위 과외 정보 페이지 index.html을
  Python 스크립트 1회 실행으로 완전 생성.

  기존 HTML 파일을 전부 삭제하고 새로 만드는 방식.
  수정이 아닌 완전 새 생성 (overwrite).
  모든 내용을 소스 2종 + NEIS API로 생성.

입력 소스 2종:
  1. 과외지역.txt       → 지역키워드 / 도 / 시구 조합
  2. 과외키워드.txt     → 레벨4 과외 키워드 목록

추가 소스:
  3. 본문뽑기/과외/[경로]/result.html → 본문 콘텐츠 JSON
  4. NEIS API                          → 전 레벨 학원카드 실시간 호출
  5. 타이틀.txt                        → 페이지 타이틀 변형 목록 (gen_all.py와 공유)

출력:
  새로운학원/과외/[도]/[시구]/[지역키워드]/[과외키워드]/index.html

생성 스크립트 파일명: 과외.py


================================================================
[ 1. 입력 파일 구조 ]
================================================================

■ 과외지역.txt (탭 구분, 3컬럼)
  컬럼1: 지역키워드 (실제 페이지에서 사용하는 키워드)
  컬럼2: 도
  컬럼3: 시/구

  예시:
    분당구    경기도    성남시
    일산동구  경기도    고양시
    상암동    서울특별시  마포구
    해운대구  부산광역시  해운대구

■ 과외키워드.txt (1컬럼, 1행 1키워드)
  예시:
    수학과외
    영어과외
    국어과외
    과학과외
    ...


================================================================
[ 2. 총 페이지 수 ]
================================================================

  루트(/과외/)           :     1개  (별도 index.html)
  레벨1 (도)            :    도 수
  레벨2 (시구)          :    시구 수
  레벨3 (지역키워드)    :    과외지역.txt 행 수
  레벨4 (과외키워드)    :    지역키워드 수 × 과외키워드 수

  → result.html 있는 경로만 실제 생성됨
